# Industry demonstration and viva guide

## Ubuntu retrieval demo
1. Open a terminal in `RAAI_SGC_2_COMPLETE_PROJECT`.
2. Run `source .venv/bin/activate` (after `./scripts/setup_ubuntu.sh` if needed).
3. Run `python scripts/final_audit.py` and `python -m pytest -q`.
4. Run `python -m app.gradio_app`; open `http://127.0.0.1:7860`.
5. Use a neutral query such as **What is Kubernetes?** and compare `vector`, `unweighted` and `hybrid` retrieval. Record the source URLs and scores.
6. Explain that the offline response mode is extractive, not a fine-tuned LLM. A response generated by pretrained Qwen is demonstrable only after it has actually run on Colab, with the logs saved.

## Google Colab model demo (not run in this package)
Upload the **same main project** folder to `MyDrive/RAAI_SGC_2_COMPLETE_PROJECT`, open `notebooks/06_colab_drive_inference_and_training.ipynb` using a GPU runtime and run in order. It saves real prompt results in `reports/generated/colab_three_way_predictions.json`, an empty expert scoring sheet, and GPU/runtime evidence. If reviewed and approved TRAIN questions exist, it will attempt the capped QLoRA run and save the adapter to `models/checkpoints/colab_qlora`.

## Suggested viva questions and defensible answers
- **What is the contribution?** Evaluating whether stored Markov–TF-IDF edge weights add value beyond the same graph without weights, under controlled retrieval and generation settings.
- **Have you proven improvement?** No; self-retrieval diagnostics tie for weighted/unweighted. Independent reviewed QA experiments remain necessary.
- **Is the trained sklearn classifier the LLM?** No. It is an auxiliary four-domain classification task.
- **Are the Wikipedia Q&A records approved?** No. They are drafts, not ground-truth SFT or independent evaluation labels.
- **Is Gradio a live bot?** Yes for extractive answers; it supports an optional true local LLM only when model dependencies and weights are available.
- **How do you prevent train/test leakage?** Source-level data splits, approved TRAIN-only SFT export, provenance validation, and independent evaluation separate from training examples.

## Folder operations
Keep `data/processed/master.csv`, `src`, `app`, `training`, `evaluation`, `tests`, and `docs`. Do not delete or overwrite human reviewer work. GPU checkpoints are written only by real runs, not bundled by default.
